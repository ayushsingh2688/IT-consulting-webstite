# Inonetecx IT Consulting Website

A responsive static website for Inonetecx Inc. The site presents the company's services, solutions, portfolio, team, testimonials, and contact flow in a polished single-page experience.

## Highlights

- Responsive layout for desktop, tablet, and mobile screens
- Sticky navigation with mobile menu support
- Hero section with animated counters and call-to-action buttons
- Services, solutions, portfolio, team, testimonial, and contact sections
- Portfolio filtering and testimonial slider interactions
- Contact form validation handled with vanilla JavaScript
- Scroll animations using AOS and icons from Font Awesome

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- AOS animation library
- Font Awesome icons

## Project Structure

```text
.
|-- html 1.html     # Main website page
|-- style.css       # Layout, theme, and responsive styles
|-- script.js       # Navigation, animation, slider, and form logic
`-- README.md
```

## Run Locally

```bash
git clone https://github.com/ayushsingh2688/IT-consulting-webstite.git
cd IT-consulting-webstite
python -m http.server 8000
```

Then open `http://localhost:8000/html%201.html` in your browser.

You can also open `html 1.html` directly in a browser without running a server.
